# Week_4_Sales_Analysis_Capstone
Sales Analysis and Prediction using Python, Excel, Linear Regression and Power BI.
Week 4 – Sales Analysis and Prediction Capstone Project

Project Overview

This project focuses on analysing sales data, identifying business trends, and predicting sales using Python, Excel, and Power BI.

Tools Used

- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Microsoft Excel
- Microsoft Power BI

Project Activities

1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Sales trend analysis
4. Linear Regression modelling
5. Sales prediction and model evaluation
6. Power BI dashboard development
7. Business findings and recommendations

Model Performance

- MAE: 82,876.54
- MSE: 13,051,783,059.06
- RMSE: 114,244.40
- R² Score: 0.7643

Deliverables

- Python notebook
- Cleaned sales dataset
- Excel analysis and dashboard
- Power BI dashboard
- Final project report (Word and PDF)

Conclusion

The project demonstrates how data analysis, machine learning, and visualisation can support business sales analysis and decision-making.
